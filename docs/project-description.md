
# Smart Business Management System

## 1. Project Description

The Smart Business Management System is a C++ application designed to help small and medium-sized businesses manage their daily operations.

The system combines inventory management, sales management and financial management into one application.

It allows users to track products, record transactions, monitor income and expenses, calculate profits and losses and analyze business performance.

The application will include a graphical user interface (GUI) to make it easier for users to interact with the system.

## 2. Project Objectives

The main objectives are:

1. To simplify inventory and stock management.
2. To automate sales recording and revenue calculations.
3. To track business income, expenses, profits and losses.
4. To allocate income based on user-defined percentages.
5. To visualize business growth, decline and stability.
6. To store and retrieve business records using CSV files.
7. To apply object-oriented programming principles in C++.


## 3. Functional Requirements

### 3.1 Inventory Management

The system should allow users to:

- Add new products with names, prices and quantities.
- Edit and delete existing products.
- Track available stock and materials.
- Automatically update stock when a sale is recorded.
- Display alerts when stock reaches a low level.
- Search for products by name or ID.
- Save and load inventory records using CSV files.

### 3.2 Sales Management

The system should allow users to:

- Record sales transactions.
- Calculate the total amount for each sale.
- Automatically update inventory after a sale.
- Store sales history with dates and transaction IDs.
- Search and view previous transactions.
- Calculate total revenue for a selected period.

### 3.3 Financial Management

The system should allow users to:

- Record business income and expenses.
- Calculate net profit or loss.
- Track financial transactions.
- Allocate available income into different categories based on user-defined percentages.
- Ensure allocation percentages total 100%.
- Generate monthly financial summaries.

### 3.4 Business Performance Analysis

The system should allow users to:

- Display graphs showing revenue, expenses and profit or loss over time.
- Compare business performance across months.
- Identify periods of growth, decline or stability.
- Calculate percentage changes between periods.
- Display financial trends using a graphical interface.


## 4. Non-Functional Requirements

- The system should be easy to use and navigate.
- The application should have a clear graphical user interface.
- Business records should be stored in CSV files.
- The system should validate user input to prevent errors.
- Financial calculations should be accurate.
- The application should handle missing or invalid data.
- The code should follow object-oriented programming principles.
- The system should be modular and easy to maintain.
- The application should include unit tests.

## 5. Expected Results

The completed application should allow businesses to manage inventory, sales and financial records efficiently.

Users should be able to monitor stock levels, record sales, calculate profits and losses and allocate funds according to their preferred percentages.

The system should also display graphs showing periods of business growth, decline or stability.

## 6. Development Tools

- C++17 - Main programming language.
- Visual Studio 2022 - Development environment.
- CMake - Build system.
- Qt - Graphical user interface.
- CSV - Data storage.
- GitHub - Version control and collaboration.
