# Smart Business Management System

A C++ application designed to help small and medium-sized business manage their daily operations efficiently.

## Project Overview

The system provides inventory management, sales tracking and financial management in one application.

It allows user to monitor stock, record sales, calculate profits and losses, allocate income into different categories based on user defined percentages and visualize the business performance through graphs showing growth, decline or stability.

## Technologies used
- C++17
- Visual Studio 2022
- CMake
- CSV files for data storage
- Qt for graphical user interface
- Git and GitHub for version control
